# HynixMON GO

꽃 캐릭터를 수집하는 복지 트레이너 웹 PoC입니다.

- 공개 앱: https://choihyun-1110.github.io/hynixMonGo/
- AI 트레이너: Claude Sonnet 5.5, Sites 서버에서 Anthropic Messages API 호출
- 팀대항전: 공식 SK하이닉스 채용 직무명 R&D 공정, 소자, Product Engineering, 양산기술, 양산관리
- 입사동기: 김민영, 윤홍빈, 최현, 신재호, 김상훈, 허승현

## 실행과 배포

index.html을 정적 웹 서버에서 제공합니다. GitHub Pages는 main 브랜치 루트를 사용합니다. GPT API 키는 Sites의 ANTHROPIC_API_KEY 비밀 변수에만 저장합니다. 프런트엔드나 GitHub에 API 키를 넣지 않습니다. 서버 소스는 server 폴더를 참고하세요.

## Claude 대화

질문과 최근 대화 최대 12개, 최소 자격 조건(근무지·자녀 수·VIP·기숙사·근속 개월)을 서버와 Anthropic에 전달합니다. 이름, 사번, 증빙 파일은 전달하지 않습니다. 대화 기록은 해당 브라우저에 저장하며 서버 DB에는 대화 내용을 저장하지 않습니다. 전체 하루 100회, 분당 15회, IP당 분당 5회 제한을 D1 데이터베이스에서 검사합니다. IP는 해시 처리하며 질문/답변은 서버 DB에 저장하지 않습니다.

## 데모 범위

Claude 대화는 실제 LLM 응답입니다. 서버 비밀 변수에 API 키를 등록했으며 실제 답변을 확인했습니다. 복지 규정·금액·활용률·예약·HR 제출/승인은 예시이며 사내 시스템에 연결되어 있지 않습니다. 팀 직무명은 공식 채용 목록에 근거한 예시 팀입니다. 입력한 팀원의 활용률은 실제 개인정보가 아닌 샘플 수치입니다. 실제 OCR·RAG·결제·예약 연동은 포함하지 않습니다.

프로필·포획·신청·대화는 각 브라우저에 저장됩니다. 영수증 원본 이미지는 저장하거나 외부 전송하지 않습니다. 실제 개인정보 대신 데모 정보를 입력하세요.
