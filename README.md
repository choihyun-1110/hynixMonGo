# HynixMON GO

꽃 캐릭터를 수집하는 복지 트레이너 인터랙티브 웹 PoC입니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버로 제공합니다. 외부 라이브러리, 별도 빌드 또는 API 키는 필요하지 않습니다.

## GitHub Pages 배포

저장소 Settings → Pages → Build and deployment에서 Source를 `Deploy from a branch`, Branch를 `main`, Folder를 `/(root)`로 설정하고 저장합니다.

## 기능

프로필 규칙 기반 복지 매칭, 위치 시뮬레이터, 혜택 계산, 증빙 이미지 미리보기·수동 확인, 포획·도감·XP·뱃지, 생애 이벤트 신청·승인 시뮬레이션, 활용률 랭킹을 지원합니다.

채팅은 사용자 메시지·답변 중 상태·규칙 기반 응답을 대화창에 표시하며 최근 100개 메시지를 브라우저에 저장합니다. 집 구입 관련 문의는 등록되지 않은 지원금을 생성하지 않고 주거 규정 확인을 안내합니다. 신청서 준비는 답변의 버튼으로 진행합니다.

## 데모 범위

복지 규정, 금액, 병원, 팀 정보는 예시입니다. 실제 AI·OCR·RAG, 사내 HR·결제·예약 연동은 포함되지 않습니다. 제출·승인은 시뮬레이션입니다. 이미지가 자동 인식된 것으로 처리하지 않으며 수동 확인 후 데모 인증합니다.

프로필, 대화, 포획, 신청 내역은 각 방문자의 브라우저 localStorage에만 저장됩니다. 영수증 원본 이미지는 저장하거나 외부 전송하지 않습니다. 프로필 메뉴의 데모 초기화로 저장된 내용을 지울 수 있습니다. 실제 개인 정보 대신 데모 정보를 입력하세요.
